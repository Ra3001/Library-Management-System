# Project Statement

## Problem Statement
A library needs a simple system to maintain information about books and students and to manage the issue and return of books. Manual management can make searching, updating, and tracking circulation difficult.

The proposed Library Management System provides a menu-driven solution using basic Python programming and data structures covered in the semester syllabus.

## Scope
The system covers:
- Book registration
- Book searching
- Book updating and deletion
- Student registration
- Book issue and return
- Fine calculation
- Transaction viewing
- Library statistics

The system does not include a database, login system, web interface, or graphical user interface.

## Target Users
- College library operator
- Faculty supervising a student project
- Students using the system for demonstration

## High-Level Features
1. Book management
2. Student management
3. Book circulation
4. Fine calculation
5. Transaction tracking
6. Library statistics

## Inputs
- Book ID
- Book title
- Author
- Category
- Student ID
- Student name
- Course
- Number of days borrowed
- Menu choice

## Outputs
- Book lists
- Student lists
- Search results
- Issue/return confirmation
- Fine amount
- Transaction records
- Library statistics

## Assumptions
- IDs are positive integers.
- Book IDs and student IDs are unique.
- A book can be issued to only one student at a time.
- The standard loan period is 14 days.
- The fine is Rs. 5 per day after the 14-day period.
- Data is stored only during program execution.

## Objectives
- Apply Top Down Design to a real-world problem.
- Implement algorithms using Python.
- Use functions and parameters to divide the program into modules.
- Apply lists, tuples, sets, and dictionaries.
- Implement searching, counting, and summation.
- Validate user input.
- Analyze basic time complexity.
- Demonstrate the complete project using GitHub.
